# 刘禹博 · 个人主页

从一个想法到一个产品。

最终灰色版本，包含个人介绍、作品与实验、文章和联系方式。原生 HTML、CSS、JavaScript，无需构建。

- 默认灰色壁纸，无换肤按钮；桌面端支持轻微鼠标视差。
- 支持手机布局和减少动态效果偏好。
- 作品与文章目前为明确标注的示例，后续可替换为真实内容。

本地预览：在本目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。

`index.html` 为页面，`styles.css` 为样式，`script.js` 为交互与示例内容。图片与页面同目录，便于直接上传和静态托管。

## AI 与产品主题灰色像素壁纸

以之前使用的 Macintosh 灰色壁纸为编辑底图，通过图像编辑替换为 AI 芯片、对话、产品仪表盘、流程、评测清单、看板和数据图表等元素。保留灰色像素块、斜向构图和柔和阴影。底图来源：https://basicappleguy.com/haberdashery/macintoshwallpapers 。

网页沿用原来的 cover 单张背景、四周 4% 扩展、灰度与亮度滤镜、0.78 透明度、白色渐变遮罩，以及原来的鼠标跟随幅度。触屏与减少动态效果偏好下静态显示，无换肤按钮。

微信二维码仍为所有者提供的原始图像。按钮、卡片与弹窗沿用统一圆角层级。

## 交互动效

背景使用按时间计算的临界阻尼跟随，鼠标静止后收敛并停止绘制，弹窗打开时暂停；不自动播放。按钮提供轻微按压反馈，项目切换约 420ms，弹窗进入约 360ms、退出约 180ms。支持连续操作与系统减少动态效果设置。关闭弹窗后恢复触发按钮的焦点。

## 联系区域

采用简短邀请、发邮件与复制微信号两个操作、辅助联系信息，以及小尺寸二维码的布局。桌面左右排列，手机上下排列；背景只在本区域柔和淡化。邮箱与手机仍可点击，微信复制结果通过状态文字反馈。
