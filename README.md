# 刘禹博 · 个人主页

从一个想法到一个产品。

原生 HTML、CSS、JavaScript，无需构建与依赖。包含「关于 / 作品 / 文章 / 联系」四个区块；外观跟随系统浅色或深色；连续三击左上角 LIU YUBO 进入 Apple 航拍地球壁纸彩蛋，再次三击返回系统外观。

本地预览：在本目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。

- `index.html`：页面结构
- `styles.css` / `liquid-glass.css` / `appearance.css`：版面与玻璃材质、外观切换
- `script.js` / `liquid-glass.js` / `appearance.js`：交互、指针高光与壁纸彩蛋
- `assets/`：背景纹理、作品示意图、微信二维码与地球壁纸素材

线上地址：https://liuyvbo2026.github.io/
